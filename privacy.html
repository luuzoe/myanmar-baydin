ကိုယ်ရေးကိုယ်တာ မူဝါဒ

နောက်ဆုံး အပ်ဒိတ် — ၂၀၂၆ ခုနှစ်၊ နိုဝင်ဘာလ ၈ ရက်

၁။ စုဆောင်းတဲ့ အချက်အလက်

ဒီ site မှာ အကောင့် ဖွင့်စရာ မလိုပါ။ မွေးနေ့၊ မွေးချိန်လို အချက်အလက်တွေကို သင့် browser ထဲမှာပဲ တွက်ချက်ဖို့ သုံးပါတယ် — server ဆီကို ဘာမှ ပို့တာ မရှိပါ။ သိမ်းထားတဲ့ ဟောစာတမ်းတွေလည်း သင့် စက်ထဲမှာပဲ (localStorage) သိမ်းထားပါတယ်။

၂။ Analytics

Google Analytics code ကို site မှာ ထည့်ထားပေမဲ့ Measurement ID မသတ်မှတ်ရသေးလို့ အခုအချိန်မှာ analytics data ဘာမှ စုဆောင်းနေတာ မရှိပါ။ ID သတ်မှတ်ပြီးရင် Google Analytics က အမည် မသိတဲ့ အသုံးပြုမှု အချက်အလက် (စာမျက်နှာ ကြည့်ရှုမှု အရေအတွက် စသဖြင့်) ကို စုဆောင်းပါလိမ့်မယ်။

၃။ ကြော်ငြာ

Google AdSense code ကို site မှာ ထည့်ထားပါတယ်။ Google က site ကို approve လုပ်ပြီးရင် Google က ကြော်ငြာ ပြဖို့ cookie တွေ သုံးနိုင်ပါတယ် (ကိုယ်ကြိုက် ကြော်ငြာတွေ အပါအဝင်)။ Google Ads Settings မှာ ကိုယ်ကြိုက် ကြော်ငြာကို ပိတ်လို့ ရပါတယ်။

၄။ Cookie နဲ့ browser သိမ်းဆည်းမှု

ဘာသာစကား ရွေးချယ်မှုနဲ့ သိမ်းထားတဲ့ ဟောစာတမ်းတွေကို သင့် browser ထဲမှာပဲ သိမ်းပါတယ်။ ဒီ site ကိုယ်တိုင် cookie မသုံးပါ။

၅။ ပြင်ပ ဝန်ဆောင်မှုများ

စာလုံးပုံစံ (Padauk, Noto Serif Myanmar) ကို Google Fonts ကနေ ယူပါတယ်။ ဂြိုဟ် တွက်ချက်မှုကို သင့် browser ထဲမှာပဲ လုပ်ပါတယ် (Astronomy Engine) — ပြင်ပ server ဆီ ဘာမှ မပို့ပါ။

၆။ မူဝါဒ ပြောင်းလဲမှု

ဒီ မူဝါဒ ပြောင်းရင် ဒီ စာမျက်နှာမှာပဲ အပ်ဒိတ် လုပ်ပါမယ်။ အပ်ဒိတ်လုပ်တဲ့ ရက်စွဲကို အပေါ်မှာ ဖော်ပြထားပါတယ်။

Privacy Policy — English summary

This site needs no account. Birth dates and times are used only inside your browser to calculate readings and are never sent to any server. Saved readings stay on your device (localStorage). Google Analytics code is present but no Measurement ID is configured yet, so no analytics data is currently collected. Google AdSense code is present; once Google approves the site, Google may use cookies to show ads. Fonts load from Google Fonts. This policy may change; the updated date is shown above.
